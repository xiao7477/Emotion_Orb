# 球面结构与材质

太阳角色沿用 `components/skull-orb/package/src/sphere/geometry.ts` 的关键做法：脸部点先定义在单位球的可见表面，再随 yaw 和 pitch 转动，最后用透视相机投影；落到球体背面的路径在视平线处裁掉。因此眼睛和嘴巴跟随的是球面，不是一张独立的平面贴图。

## 造型层次

- 球体用一组径向渐变表达同一块橙金色外壳，左上为受光面，右下自然变深。
- 14 枚圆锥按 Fibonacci 球面分布生成。朝前的一枚增大底面和高度、尖端略向上偏，作为鼻子；其余圆锥保持统一尺寸。
- 每枚圆锥由球面圆形底缘和三角锥面组成；背面圆锥先画，再绘制球体遮挡，正面圆锥后画。
- 眼睛先画橙色压痕边缘，再画暗色眼窝、内嵌眼球和瞳孔；鼠标方向只给瞳孔一个小幅偏移。
- 嘴巴按球面曲线围出暗腔，再加窄的暖色上沿、牙齿和舌头。上下边缘的明暗差表现向内凹的深度。

## 交互

组件把指针在自身范围内的位置映射到球体 yaw/pitch，并通过短弹性过渡更新球面路径。指针离开后，球面和视线回到正面。组件尊重系统减少动态偏好，静态表情缩略图不启动指针动画。
