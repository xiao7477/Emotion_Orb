# 骷髅材质

面罩、尖牙与手势使用一致的白色表面和柔和侧向明暗；黑色球体与头罩保持同一套高光方向。SVG 路径随视角投影和遮挡，鼠标移动时共同旋转，保持球面体积感。

这不是物理 3D 渲染。它使用 SVG 几何、明暗渐变和投影表达体积；画布中不加载第三方 Emoji 图片或模型。

## 黑色角色的逆光

`form="character"` 的黑色头罩与闪电共用一张连续剪影，采用微弱的中性灰白高光；不带蓝色、紫色或暖色偏色，右下反射更弱。宽而柔和的内侧光带叠加局部细高光，亮度沿高度逐渐衰减，保留大面积深黑材质。光带由剪影与偏移、柔化后的遮罩相减得到，不新增描边，也不扩大角色的透明边界。

光源固定在画面空间；头罩转动、表情过渡和暂停时，光照剪影与原几何同步。面罩、眼窝和手势不参与这个滤镜，闪电接缝也不会因分层重复发亮。关闭 `shading` 会恢复原有纯黑外壳并隐藏逆光。普通球形形态不显示角色逆光。

这里是独立的程序化 SVG 组件。它与 [`pets/skull-orb`](../../../pets/skull-orb/README.md) 的最终宠物图集保持同一设计方向，但不会生成该图集，也不保证逐帧形状、道具和动作相同。实际宠物导入请使用图集目录中的 PNG。
