## 来源与版本

本包收录最终淡灰白修订版，替代此前较亮的双色/冷色逆光素材。设计参考与动作行经过图像生成和统一帧位整理，最终图集是运行时权威素材；行源图由最终图集无损拆出，保留实际发布像素。设计参考不应直接当作动画帧替换。

[`components/skull-orb`](../../components/skull-orb/README.md) 是独立的 React/SVG 实现，仅同步近黑身体和微弱中性光的设计方向。其表情、道具和动画不与本图集逐帧等价，也不生成本图集。

## 验证与已知差异

精确 PNG 已通过结构、透明背景和帧布局预检；最终质量检查及方向/动作审阅通过。保留原有九种动作家族与顺序。起跳前的第一帧蹲伏较原版略深，顶部约低 9–12px；起跳、最高点和落地仍连贯。少量纹理与 3–4px 轮廓宽度变化属于已接受的重绘差异。方向跨行处曾出现的明显尺寸跳变已修复。
